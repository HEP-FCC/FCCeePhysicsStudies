# A place to keep track of thoughts on studies that can be done

## ALPs

Get a comprehensive understanding of ALP production modes off the Z pole in the 2 dimensional $C_{WW}$, $C_{BB}$ parameter space. In particular, extend [2310.17270](https://arxiv.org/abs/2310.17270v2) to include $ZZ$ and $Z\gamma$ fusion 

## Heavy New Physics

Set out some benchmark heavy NP scenarios to explore in conjunction with other working groups: keep up to date observables from flavour, EW, etc. And aim to encourage direct search projections at FCC-hh.

* Linear SM extensions
* Flavour Deconstruction: $U(1)_Y$, $SU(2)_L$, and $SU(4)$ leptoquark
* Composite Higgs - both SILH EFT parametrisation (in terms of $g_\ast$, $m_\ast$) and top partner searches
